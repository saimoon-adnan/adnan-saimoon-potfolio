Netflix Movie Data Analysis

A complete Netflix Movie Data Analysis project built using Python and Pandas. Performed ETL operations, cleaned and transformed raw data, and generated valuable insights through exploratory data analysis and visualization on a dataset of 9,000+ movies.

Python Pandas NumPy Matplotlib Jupyter Notebook
View on GitHub

Project Visualizations

Left to right: Release date distribution · Vote distribution · Genre distribution

Project Objective

The main objective of this project is to analyze Netflix movie trends and solve real-world business questions using data analysis techniques on a dataset of 9,000+ movies.

Business Problems Solved

  • What is the most frequent movie genre on Netflix?
  • Which movie has the highest vote average?
  • Which movie has the highest popularity and what is its genre?
  • Which movie has the lowest popularity and what is its genre?
  • Which year has the highest number of released movies?

ETL Process

Extract

Loaded the raw Netflix dataset using Pandas.

Transform

  • Removed duplicate values
  • Handled missing data
  • Converted release date format
  • Split and cleaned genre values
  • Categorized vote averages
  • Removed unnecessary columns

Load

Prepared a clean dataset for analysis and visualization.

Data Cleaning Process

Several preprocessing techniques were applied to clean the dataset before analysis. This includes handling null values, formatting columns, splitting genre values, and transforming numerical data for better analysis accuracy.

Key Insights

Drama was one of the most frequent movie genres on Netflix.
Some years showed a significant increase in movie releases.
Highly popular movies do not always receive the highest vote averages.
Data visualization helped identify trends and audience preferences.

About the Dataset

The dataset contains information about Netflix movies, including:

  • Movie Title
  • Genre
  • Popularity
  • Vote Average
  • Release Date
  • Language
  • and other movie-related attributes

Conclusion

This project demonstrates practical skills in Python-based data analysis, ETL processing, and visualization techniques. It also highlights the importance of transforming raw data into meaningful business insights.
